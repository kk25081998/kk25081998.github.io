Projects

  1. 2026

    OpenClade

    Phylogenetic analysis of morphological data in the browser

    Parsimony analysis of morphological character matrices that runs entirely in the browser, with no installation and no data upload. It reads NEXUS and TNT files, including MorphoBank exports, handles inapplicable characters with the Brazeau, Guillerme and Smith (2019) algorithm, and produces most parsimonious trees, consensus trees, bootstrap support, character mapping and a methods paragraph.

    Tree lengths match TreeSearch on all 806 test trees across 31 published matrices, and the search found the exact optimum in 124 of 124 exhaustive tests.

    Open OpenClade Source code DOI 10.5281/zenodo.23634128
